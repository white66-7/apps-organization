# DesktopHelper (桌面助手)

DesktopHelper 是一款轻量级的 Windows 桌面增强工具。它可以让你通过双击桌面空白处快速隐藏或显示桌面图标,开机自启动等功能。

## ✨ 功能特性

- **双击显隐图标**：双击桌面空白处即可切换图标显示状态，支持平滑的淡出动画。
- **高性能监听**：采用异步队列处理鼠标事件，完全不占用系统资源，不产生鼠标操作延迟。
- **智能避让**：精准识别桌面图标、任务栏及窗口化应用，防止在操作其他程序时误触发。
- **设置自定义**：
    - 可调节的双击判定时间（0.1s - 1.0s）。
    - 动画效果开关。
    - 开机自启动管理。
- **轻量化**：系统托盘运行，界面简洁。

## 🚀 快速开始

### 环境准备
- Windows 10 / 11
- Python 3.8+

### 安装依赖
```bash
pip install pynput pystray Pillow
```
```text
python main.py
```
## 🛠️ 打包为 EXE
```bash
pyinstaller --noconsole --onefile --name "DesktopHelper" --add-data "resources;resources" --icon="resources/icon.ico" main.py
```

## 📖 使用说明
隐藏/显示图标：在桌面没有任何窗口遮挡的空白区域双击鼠标左键。
设置界面：右键点击右下角托盘图标，选择“设置”。
彻底退出：在设置界面点击“彻底退出程序”或通过托盘菜单退出。
## ⚠️ 注意事项
路径问题：本程序已做开机自启动路径自适应处理，请放心开启。
Windows 11 任务栏：由于 Windows 11 不同版本的渲染机制差异，部分功能在某些预览版系统中可能失效。
安全软件：由于涉及注册表修改（开机自启动）和全局鼠标钩子，部分安全软件可能会拦截，请添加白名单。
